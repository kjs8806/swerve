# Swerve

A 5-lane arcade dodge-racer: swerve between lanes to avoid traffic,
chain near-misses for speed boosts, bank coins to trigger an
invincible turbo burst, and reach the finish line before the 60-second
clock runs out.

See [`DESIGN.md`](./DESIGN.md) for the design rationale, scope
decisions, and roadmap.

## Run the game

Built in Godot 4.3+. See [`godot/README.md`](./godot/README.md) for
how to open or run the project.
